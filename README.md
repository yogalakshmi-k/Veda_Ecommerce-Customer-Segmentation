# E-Commerce Customer Segmentation & Recommendation Analysis

## Project Overview
This project uses machine learning to analyze online retail transactions, identify customer segments, and recommend similar products.

## Objectives
- Clean and preprocess retail transaction data.
- Perform RFM (Recency, Frequency, Monetary) analysis.
- Apply K-Means clustering to group customers.
- Visualize customer segments.
- Build a product similarity-based recommendation system.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab

## Machine Learning Techniques
- RFM Analysis
- StandardScaler
- K-Means Clustering
- Cosine Similarity

## Dataset
UCI Online Retail Dataset.

## Project Files
- `Ecommerce_Customer_Segmentation.ipynb` – Complete project notebook.
- `customer_segments.csv` – Customer RFM values and cluster labels.
- `segment_profiles.csv` – Summary of customer segments.
- `product_similarity_sample.csv` – Similarity scores for a sample of products.
- `customer_segments.png` – Customer segmentation visualization.

## Conclusion
The project demonstrates how machine learning can help businesses understand customer purchasing behaviour, segment customers, and identify similar products for recommendation.
